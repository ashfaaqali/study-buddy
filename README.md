# 📚 StudyBuddy – Android App (Updated Version)

An updated version of the **StudyBuddy** Android app — designed to help students manage their study sessions, notes, and tasks efficiently. Built using modern Android development practices such as **Room**, **Hilt**, **LiveData**, and **Navigation Components**.

---

## 🔧 Tech Stack

- **Kotlin**
- **XML Layouts**
- **MVVM Architecture**
- **Room Database** – for local data persistence
- **LiveData & ViewModel** – for reactive UI updates
- **Hilt** – for dependency injection
- **Navigation Component** – for seamless fragment navigation
